# 论文截图指南

本文档用于指导本科毕业论文第 5 章“系统实现”截图准备。建议统一使用 16:9 或常规浏览器窗口截图，页面尽量保持表格完整、按钮清晰、中文标签明显。

## 1. 后端项目结构图

- 建议文件名：`chapter5_backend_structure.png`
- 页面或工具：VS Code 文件树 / IDEA Project 视图
- 截图重点：`controller`、`service`、`mapper`、`entity`、`dto`、`vo`、`config`
- 论文说明建议：说明系统采用分层架构，便于业务维护与接口扩展

## 2. 数据库表结构图或 Navicat 表列表

- 建议文件名：`chapter5_database_tables.png`
- 页面或工具：Navicat / DataGrip / MySQL Workbench
- 截图重点：`user`、`book`、`book_order`、`borrow_record`、`circulation_record`、`points_record`
- 论文说明建议：突出循环共享核心表 `circulation_record`

## 3. 用户登录页面

- 论文说明建议：说明系统采用 JWT 登录认证机制

## 建议截图顺序

建议论文第 5 章按以下顺序放图：

1. 系统整体结构与数据库
2. 前台登录注册
3. 首页与书籍详情
4. 发布、申请、订单、借阅、积分
5. 再次共享与评价举报
6. 管理员后台管理页面
7. 数据库流转记录与积分记录
